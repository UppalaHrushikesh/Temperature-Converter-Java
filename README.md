# Temperature Converter (Java)

A console-based temperature converter written in Java.

## Features
- Convert Celsius ↔ Fahrenheit
- Convert Celsius ↔ Kelvin
- Convert Fahrenheit ↔ Kelvin
- Input validation
- Exception handling
- User-friendly menu
- Supports repeated conversions

## Technologies
- Java
- Scanner
- Switch expressions
- Exception Handling

## How to Run
1. Compile:
   javac TemperatureConverter.java

2. Run:
   java TemperatureConverter
